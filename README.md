# Сайт «Авто Альянс»

Одностраничный сайт без сборки и без сервера: `index.html`, шрифты в `fonts/`, фото лотов в `img/lots/`.

## Посмотреть
Откройте `index.html` в браузере.

## Фото автомобилей
Карточки работают и без фото. Чтобы они появились:
- дважды кликните по файлу «Загрузить фото.command» (скачает по 3 фото каждого лота из Telegram-канала), или
- положите свои файлы в `img/lots/` с именами `НОМЕР-1.jpg`, `НОМЕР-2.jpg`, `НОМЕР-3.jpg`, где НОМЕР это номер лота (он же номер поста в канале).

## Добавить или убрать лот
В `index.html` найдите список `const LOTS=[...]`. Каждая строка это один автомобиль:
`id` номер поста, `c` страна (jp, kr, cn), `t` название, `y` год, `hp` мощность, `eng` двигатель, `tr` коробка, `dr` привод, `km` пробег, `p` цена, `rhd:1` правый руль, `here:1` автомобиль уже во Владивостоке, `g` оценка аукциона, `note` честный нюанс.

## Заявки
Форма собирает текст и открывает чат с менеджером @Aleks_ABTO в Telegram. Телефон и ссылки на соцсети меняются поиском по файлу.

## Публикация
Папку целиком можно загрузить на любой статический хостинг: Timeweb, Beget, REG.RU, GitHub Pages, Netlify. Нужен только домен.
